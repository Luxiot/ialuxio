Tu página web

Este es un ejemplo de cómo se ve tu página con el widget de chat Luxio integrado.

El botón de chat aparece abajo a la derecha. ¡Prueba hacer clic!

Cómo agregar el widget a tu web

Copia y pega este código antes del cierre de </body>:

<script 
  src="/luxio-chat-widget.js" 
  data-api-url="http://localhost:8001"
  data-name="Luxio"
></script>

Producción: Cambia data-api-url por la URL de tu API desplegada.
