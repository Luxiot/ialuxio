# Subir CreatiWebSalta a Firebase Hosting

## 1. Instalar Firebase CLI (solo la primera vez)

```bash
npm install -g firebase-tools
```

## 2. Iniciar sesión

```bash
firebase login
```

(Usa el Gmail que tiene el proyecto **creatiwebsalta**)

## 3. Ir a la carpeta CreatiWebSalta

```bash
cd c:\Users\Luxio\Desktop\ia luxio\CreatiWebSalta
```

## 4. Desplegar

```bash
firebase deploy
```

## 5. Ver el sitio

- **URL:** https://creatiwebsalta.web.app  
- También: https://creatiwebsalta.firebaseapp.com  

---

**Nota:** Ya están creados `firebase.json` y `.firebaserc` en esta carpeta. El comando `firebase deploy` sube **solo** el contenido de CreatiWebSalta (HTML, JS, imágenes, plantillas).
